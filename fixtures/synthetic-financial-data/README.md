# Synthetic Financial Data

Only synthetic financial data belongs here.

The future fixture set should cover income, rent/mortgage, groceries, transport, subscriptions, card purchases/settlement, transfers, cash-buffer contributions, mortgage overpayments, business activity, mixed merchants, legitimate same-day/same-amount entries, duplicate cases and split purchases.

These fixtures may be reused across tests, mobile journeys and documentation.

Never add real personal bank exports.
