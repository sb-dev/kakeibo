# Getting Started

The first runnable Kakeibo is the CLI MVP.

1. Install Node.js and pnpm 10, then run `pnpm install && pnpm build` at the repository root.
2. Follow the [CLI guide](../../apps/cli/README.md) for `kakeibo init`, `kakeibo plan`, `kakeibo import`, `kakeibo review`, `kakeibo summary` and `kakeibo spending`, the generic CSV format and backup recovery.
3. Try it with the [synthetic fixtures](../../fixtures/synthetic-financial-data/csv/README.md); the [walkthrough record](../product/cli-mvp-walkthrough.md) lists every command and prompt answer of one complete run.

Onboarding for the mobile and web applications will follow when they exist.
