# Kakeibo Blog

The Blog supports discovery and current thinking without becoming a source of canonical behaviour.

```text
Kakeibo             → releases, product decisions, design changes
Kakeibo             → method, history, modern practice
Money & Behaviour   → financial reflection, habits and decision-making research
Engineering & Trust → privacy, bounded AI, open source, analytics and open banking
```

If a Blog idea becomes product behaviour, update the owning canonical spec.

Never publish identifiable financial data or personalised financial advice.
