# Security Policy

Kakeibo handles sensitive financial information.

Security issues involving authentication, authorisation, financial-data exposure, provider credentials/callbacks, Kei data leakage, analytics privacy or cross-user access must not be reported through public Issues.

## Current stage

This repository is a pre-implementation scaffold.

Before public launch, configure a private reporting route, preferably GitHub private security advisories or an equivalent private channel.

Security fixes should return to the public codebase once coordinated disclosure and release timing permit.
